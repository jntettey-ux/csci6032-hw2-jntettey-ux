# Instructions for AI Agents

- Work only inside the current repository. Do not access or modify files outside it.
- Never read, print, store, commit, or upload secrets, credentials, private keys, browser data, or configuration files that may contain them.
- Before editing, explain the intended change and its scope.
- Ask for permission before installing software, accessing a new network destination, deleting files, changing Git history, committing, or pushing.
- Preserve uncommitted user work. Avoid destructive Git commands and never force-push.
- Check `git status` before editing. If unrelated changes are present, stop and ask for guidance.
- Make small, focused, reviewable changes.
- After editing, show `git diff` and run the smallest relevant test or validation command.
- Explain errors clearly; never silently ignore failures.
- Never claim success without checking that the requested result was produced and works as expected.
